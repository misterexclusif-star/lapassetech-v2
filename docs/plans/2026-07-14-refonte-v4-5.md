# Refonte v4.5 — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal :** Porter le design v4.5 (maquettes `~/Downloads/lapassetech-*-v4-5.html`) dans le site Astro existant, sur la branche `refonte-v4-5`.

**Architecture :** On garde l'ossature du repo (BaseLayout + composants + sections Homepage* + collections). On ajoute une couche CSS `v45.css` au design system contenant les composants maquette (classes `.btn`, `.qcard`, `.ticket`…), puis on réécrit les sections/pages une à une sur le markup maquette. Les tokens `--lpt-*` restent la source de vérité ; les variables maquette (`--caramel`, `--jaune`…) deviennent des alias.

**Tech stack :** Astro 6 (content layer, glob loader), CSS vanilla (design system maison), zéro dépendance nouvelle.

**Spec :** `docs/specs/2026-07-14-refonte-v4-5-design.md` — les règles globales de la section « Global Constraints » ci-dessous en sont extraites.

## Global Constraints

- Vert `#16B877` : uniquement le point de statut PassBot. Jamais en CTA, badge, tick ou surligneur.
- Jamais de texte/élément jaune sur fond noir (association Tademy).
- CTA = jaune `#F5C542` ; ambiance = caramel `#9C5A2C` ; fonds sombres chauds = `#5C2E10` (sections) et `#1A1714` (footer) ; accents sur sombre = terracotta `#C97C4A`.
- Bordures composants : `2px solid` noir ; ombre signature `6px 6px 0` (cartes) / `4px 4px 0` (petits éléments) ; radius cartes `18px`.
- Toute animation respecte `prefers-reduced-motion` (déjà le pattern du repo).
- Copy : tutoiement, encadrés « La vérité : », dates explicites (« à jour · avril 2026 »).
- Après chaque tâche : `npm run build` doit passer, puis commit.
- Vérification visuelle : screenshot headless Chrome de la page modifiée comparé à la maquette correspondante (`~/Downloads/lapassetech-<page>-v4-5.html`).
